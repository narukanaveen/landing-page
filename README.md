# Odin Project: Landing Page

https://narukanaveen.github.io/landing-page/

This is a solution to the [Landing Page project](https://www.theodinproject.com/lessons/foundations-landing-page) from The Odin Project's Foundations course. The goal of this project is to build a complete, modern responsive webpage from scratch using HTML and CSS Flexbox based on a provided design layout.

## 🛠️ Built With

- **HTML5** - Semantic markup structure
- **CSS3** - Custom properties, typography layouts, and positioning
- **Flexbox** - Primary layout model used for alignment and spacing

## 🧠 What I Learned

- Designing layouts from scratch using a conceptual static mockup image.
- Advanced structuring of content layouts using CSS Flexbox containers, direction properties, and alignment tools.
- Managing multiple nesting layers of flex elements without breaking layouts.
